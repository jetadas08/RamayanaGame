Research-only design dossier. No player-facing copy, graph data, UI, or quote is approved by the existence of this document. The existing Family & Origins slice remains the baseline and is not changed here.

## A. KIṢKINDHĀ RESEARCH SUMMARY

The Kiṣkindhā lens should explain a **network of kinship, contested kingship, alliance, counsel, and a shared search**, rather than place every character around Hanumān. The strongest playable route is Hanumān → Sugrīva → Vāli → Tārā/Aṅgada, with a second route Hanumān → Rāma → Sugrīva and a mission route Aṅgada → Jāmbavān → Hanumān. An edge can carry more than one meaning, but its displayed label should name the concrete relation first; interpretation belongs in the explanation.

## C. RELATIONSHIP MATRIX

`Direct` means a kinship tie or a narrated interaction/commitment between the pair; it does **not** automatically mean a harmonious or enduring bond. `Contextual` means the pair has a real narrated encounter but its primary explanatory path is through another relationship or later story moment. `Indirect` means no direct pair-edge has been established for this lens. `Core`, `supporting`, and `background` describe *learning importance*, not spiritual rank. `Image checked` means a representative original VR1 page was visually checked; `locator check` means the approved edition was located with OCR/text but that exact claim needs an additional original-page check. Every “app may say” phrase is a paraphrase candidate; none is an approved exact quote.

## D. DIRECT / CONTEXTUAL / INDIRECT CLASSIFICATION

- **Direct, core Build candidates:** K01–K08, K10–K12. These represent attested kinship, commitments, companionship, and narrated counsel. Verification tasks in §N still apply.
- **Direct but contextual to the first Build experience:** K09, K13–K18, K20. These pairs interact or have attested kinship in the approved sources. They should not be erased simply because the first challenge omits their edges. Source notes and Explore explain their timing and complexity.
- **Indirect for this lens:** K19 Hanumān–Vāli. A false direct edge would disguise the very multi-hop structure this lens should teach.
- **Potentially misleading graph shorthand:** “Tārā belongs to Hanumān's family,” “Rāma and Vāli are allies,” “Lakṣmaṇa and Sugrīva are enemies,” “Jāmbavān grants Hanumān power,” and “Aṅgada serves without tension.” Reject these even if a visual graph would be simpler.

## E. PROPOSED GRAPH ARCHITECTURE

Use eight first-release nodes and a **layered, multi-hop** graph. This is information architecture, not UI implementation:

```text
                        Rāma
                         │ alliance
Hanumān ─ envoy ─ Sugrīva ─ brothers/conflict ─ Vāli
   │                    │                         ├── spouse/counsel ─ Tārā
   │                    └── uncle/heir ─ Aṅgada ──┘ parents
   │                                    │
   └── search companions ───────────────┤
                    Jāmbavān ─ counsel ┘
                        └── reminds Hanumān

Lakṣmaṇa: Rāma's brother; first-embassy context with Hanumān; later
accountability with Sugrīva and counsel from Tārā (Explore-first cross-links).
```

This sketch shows conceptual paths, not an exact visual layout or exhaustive adjacency. Suggested graph neighborhoods from Hanumān: **direct edge** to Sugrīva, Rāma, Lakṣmaṇa, Aṅgada, Jāmbavān, and Tārā (the last as Explore-only); **one intermediate character** to Vāli through Sugrīva or to Tārā through Aṅgada when the direct Explore edge is hidden; **two intermediate characters** to Tārā through Sugrīva → Vāli. The graph should expose whichever shortest *approved* path is relevant, rather than assert only one canonical route.

Default Build edge labels should be concrete (“brothers in conflict,” “mother and son,” “mutual alliance,” “southern search companions”). Detail panels can add time and source context. Conflict can be drawn differently from kinship/alliance, but avoid a universal “bad relationship” color. Any revealed political edge should preserve the period before and after Vāli's death. This lens must never imply all eight characters are simultaneously present in one scene.
