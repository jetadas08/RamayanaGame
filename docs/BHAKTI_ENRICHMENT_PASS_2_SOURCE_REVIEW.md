## H. Rejected or deferred material (five claims)

1. **Name-inscribed floating stones as VR or RCM fact — rejected.** The accessible RCM bridge locus supports Rāma's grace and floating stones, not an inscription. A later-tradition witness has not been approved.
2. **“Eight siddhis” assigned to every game ability — deferred.** No selected source in this review supplies a responsible node-by-node taxonomy; it would gamify an interpretive layer.
3. **One Sañjīvanī herb cures only Lakṣmaṇa in both Chapter VII rescues — rejected.** [VR Yuddha 74](https://www.valmikiramayan.net/utf8/yuddha/sarga74/yuddhasans74.htm) and [101](https://www.valmikiramayan.net/utf8/yuddha/sarga101/yuddhaitrans101.htm) are distinct crises and name multiple herbs.
4. **HJ-09's pre-Sītā Vibhīṣaṇa meeting attributed to VR — rejected.** This chronology belongs to the [RCM Sundara telling](https://www.ramcharitmanas.iitk.ac.in/type/verse?page=997), not the later [VR Yuddha refuge council](https://www.valmikiramayan.net/utf8/yuddha/sarga17/yuddha_17_prose.htm).
5. **A new finale quotation or reward linked to Sītā's necklace — deferred.** [VR Yuddha 128](https://www.valmikiramayan.net/utf8/yuddha/sarga128/yuddha_128_prose.htm) has the narrative episode, but it is not a new Sacred Object collectible and the current closing line is already sufficient.
